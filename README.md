# CloudDrive — етап 2 (десктоп-клієнт + сервер)

Система типу 2, варіант 1: клієнт для взаємодії з віддаленою папкою.
Типи для перегляду — **.xml** (як текст) і **.png** (як зображення).
Операція варіанта — **сортування за датою і часом створення** (зростання/спадання)
та **фільтр «усі файли / лише .xml, .png»**.

Стек: Python 3.11 · PySide6 (GUI) · FastAPI (REST API) · PostgreSQL · pytest.

---

## 2. Що встановити (один раз)

1. **Python 3.11** — уже є.
2. **PostgreSQL** — postgresql.org → Download → Windows. Під час установки запам'ятайте пароль користувача `postgres`.
3. **VS Code** + розширення «Python» від Microsoft.

---

## 3. Підготовка проєкту

Розпакуйте архів, відкрийте теку `clouddrive` у VS Code (File → Open Folder).
Далі всі команди — у вбудованому терміналі VS Code (`Ctrl + ~`), **з кореня проєкту**.

### 3.1. Віртуальне середовище та бібліотеки

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Якщо PowerShell блокує активацію, виконайте один раз:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

У VS Code: `Ctrl+Shift+P` → **Python: Select Interpreter** → оберіть `.venv`.

### 3.2. База даних

Відкрийте **pgAdmin 4** → підключіться до сервера → правою кнопкою на `Databases` →
**Create → Database** → ім'я `clouddrive` → Save.

### 3.3. Файл .env

Скопіюйте `.env.example` у `.env` і підставте свій пароль:

```
DATABASE_URL=postgresql+psycopg://postgres:ВАШ_ПАРОЛЬ@localhost:5432/clouddrive
```

### 3.4. Створення таблиць і демо-користувачів

```powershell
python -m server.init_db
```

Буде створено таблиці `users`, `files` і двох користувачів:
`sofiia / qwerty123` та `ivan / qwerty123`.

---

## 4. Запуск

Потрібні **два термінали** (у VS Code: кнопка «+» у панелі термінала).

**Термінал 1 — сервер:**
```powershell
uvicorn server.main:app --reload
```
Перевірка: у браузері `http://127.0.0.1:8000/docs` — відкриється Swagger з усіма ендпоінтами.

**Термінал 2 — клієнт:**
```powershell
python -m client.app
```
У вікні входу: логін `sofiia`, пароль `qwerty123`, адреса сервера за замовчуванням.

## 6. Що показати у звіті (план скріншотів)

Функціонал уже реалізований — лишається його відзняти. Рекомендований порядок:

1. **Структура проєкту** у VS Code (дерево тек).
2. **Swagger** `http://127.0.0.1:8000/docs` — перелік ендпоінтів.
3. **pgAdmin**: таблиці `users` і `files` із даними.
4. **Вікно входу**; окремо — спроба входу з невірним паролем (повідомлення про помилку).
5. **Головне вікно** з таблицею і всіма стовпцями (назва, тип, розмір, створено, змінено, хто завантажив, хто редагував).
6. **Сортування за датою створення**: два скріни — ▲ (зростання) і ▼ (спадання) — видно різний порядок рядків.
7. **Фільтр**: «Усі файли» → «Лише .xml і .png» — два скріни.
8. **Меню «Стовпці»**: знятий прапорець, стовпець зник із таблиці (і видно, що «Назву» вимкнути не можна).
9. **Перегляд .xml** у правій панелі (як текст) і **перегляд .png** (як зображення) — два скріни.
10. **Завантаження**: діалог вибору файлу + результат у таблиці.
11. **Drag-and-drop**: перетягування файлу у вікно (бонус) і поява його в таблиці.
12. **Вивантаження** файлу на диск і **видалення** з підтвердженням.
13. **Синхронізація**: вікно з планом («↑ завантажити», «↓ вивантажити», «= без змін») і результат після виконання.
14. **Тести**: вивід `pytest` із 28 passed.

Для пунктів 5–13 зручно спочатку завантажити файли з теки `demo_files`
(там є 2 файли .xml, 2 .png і 1 .txt — одразу видно, як працює фільтр).

## 7. Типові проблеми

| Симптом | Причина й рішення |
|---|---|
| `password authentication failed for user "postgres"` | невірний пароль у `.env` |
| `database "clouddrive" does not exist` | не створено базу в pgAdmin (крок 3.2) |
| `Сервер недоступний` у клієнті | не запущено `uvicorn` у першому терміналі |
| `ModuleNotFoundError: server` / `common` | команду запущено не з кореня проєкту |
| Вікно клієнта не відкривається | не активоване `.venv` або не встановлено PySide6 |
| Порт 8000 зайнятий | `uvicorn server.main:app --reload --port 8001`, ту саму адресу вкажіть у вікні входу |
